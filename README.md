#Личные ожидания от курса

Как по мне этот курс должен быть максимально интересным. Этот курс может предоставить совсем другие ощущения от использования компьютера. 
Уметь использовать другие операционные системы(кроме Windows), может оказатся весьма полезным навыком. Например, можно начать хостить собственный сервер, 
работать с мини ПК или настраивать микро контроллерами. В конце концов по мимо Windows есть ещё и MacOSX которая славится своим функционалом и удобством или любой Linux дистрибутив
который как правило бесплатный, безопасный и гибконастраеваемый, и каждый может выбрать что ему по душе.
